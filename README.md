# Kavin Kumar L - Portfolio Source Code

This ZIP archive contains the complete, self-contained source code for Kavin Kumar L's portfolio website.

## 📂 Included Files
- `index.html`: Complete webpage containing layout, content, design tokens, Tailwind CSS styling, and interactive features.
- `README.md`: Setup and deployment instructions.
- `package.json`: Project metadata for quick local previews.

## 🚀 How to Run
1. Extract all files from this ZIP package.
2. Open `index.html` in any web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
3. No server or node installation required!

## 🌐 How to Host Online
- **GitHub Pages:** Upload `index.html` to a GitHub repository, go to **Settings > Pages**, and select the main branch.
- **Vercel or Netlify:** Drag and drop the extracted folder directly onto the Vercel or Netlify dashboard.
